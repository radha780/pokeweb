# pokeweb

This project is a simple website made with HTML and CSS that displays information and images of different Pokémon and their evolutions.

## Project Structure

```
pokeweb/
│
├── index.html
├── index1.html
├── index2.html
├── index3.html
├── index4.html
│
├── images/
│    ├── charmander.png
│    ├── squirtle.jpg
│    ├── bulbasaur.jpg
│    ├── pikachu.jpg
│    ├── eevee.jpg
│    ├── charmeleon.jpg
│    ├── charizard.jpg
│    ├── ivysaur.jpg
│    ├── blastoise.jpg
│    ├── pokemon-ball.jpg
│
└── README.md
```

## How to Use

Open any of the HTML files in a browser to view the Pokémon information.
